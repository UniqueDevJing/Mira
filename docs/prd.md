## 1. 产品概述

### 1.1 产品定位
面向企业的智能文档处理与知识库问答系统，支持 PDF 文档上传、自动语义分析、知识图谱构建、自然语言问答。

### 1.2 目标用户
| 用户角色 | 核心需求 | 使用频率 |
|---------|---------|---------|
| 知识管理岗 | 上传文档、管理知识库 | 日常 |
| 业务查询者 | 自然语言提问，获取精准答案 | 高频 |
| 系统管理岗 | 监控系统状态、管理权限 | 低频 |

### 1.3 核心价值主张
- **零门槛检索**：用自然语言向企业知识库提问，无需学习查询语法
- **来源可追溯**：每个答案标注引用来源，支持溯源验证
- **图表谱联动**：向量精准匹配 + 知识图谱多跳推理，比纯关键词搜索召回率提升 30%+
- **本地化部署**：全离线可用，数据不出境

## 3. 功能列表

### 3.1 已实现 (Phase 1-3)
- [x] PDF 文档解析（PyMuPDF + PDFPlumber 双引擎）
- [x] 扫描件 OCR 识别（PaddleOCR）
- [x] 语义分块（标题树 + 相似度低谷）
- [x] 向量嵌入（BGE-small-zh-v1.5, 512d）
- [x] 向量存储（LanceDB 嵌入式）
- [x] 混合检索（稠密向量 + 图谱增强）
- [x] 知识图谱构建（规则 + LLM 混合抽取）
- [x] Cross-Encoder 重排序
- [x] Self-Retrieval 多轮自适应检索
- [x] LLM 答案生成（带来源引用）
- [x] Web 前端（三标签页 SPA）
- [x] RESTful API（文档上传/状态/列表、QA 问答）
- [x] **Router + Skill 多技能架构**（IntentRouter 规则+LLM 路由 → 客服/技术双库 + 直接回答，向量+BM25 并行 RRF 融合，分阶段超时/降级，跨库兜底）

### 3.2 待实现 (Phase 4-6)
- [ ] 文档删除 API 及前端功能
- [ ] 批量文档上传
- [ ] 按部门/标签过滤检索
- [ ] Neo4j 图数据库持久化（当前为内存存储）
- [ ] Milvus 生产环境向量库
- [ ] Celery 异步文档处理
- [ ] Redis 限流与缓存
- [ ] API Key 认证中间件
- [ ] Prometheus + Grafana 监控
- [ ] 前端升级（Next.js + shadcn/ui）
